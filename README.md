# Samuel Sebastian Guzman Roa Parcial Movil
Aplicación web desarrollada con Ionic y Angular.
Requisitos

- Node.js y npm instalados.
- Ionic CLI instalado. Si el comando `ionic` no está disponible, instálalo con `npm install -g @ionic/cli`.

Instalación
Desde la carpeta del proyecto, instala las dependencias:
-npm install

Ejecutar en modo desarrollo
-ionic serve
-El servidor abrirá la aplicación en el navegador, normalmente en [http://localhost:8100]
